# MiniTweet – Django Microblogging Platform

MiniTweet is a **Twitter-style microblogging web application** built using the Django framework.  
Users can create accounts, post short messages, and manage their posts dynamically.

This project demonstrates backend development using Django's **Model–View–Template (MVT) architecture** along with database integration using Django ORM.

---

## Tech Stack

- Python
- Django
- HTML
- CSS
- Git

---

## Features

- User registration and login
- User authentication system
- Create posts (tweets)
- Edit and delete posts
- Dynamic content rendering
- Database integration using Django ORM
- Admin panel for managing data

---

## Project Architecture

This project follows Django's **MVT architecture**:

- **Model** – Database structure and data handling
- **View** – Application logic
- **Template** – Frontend rendering
